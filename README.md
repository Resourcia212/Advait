## How to Open & Run the Website

### Option 1: One-Click Production Viewer (No Server Needed)
- Double-click **`VIEW_STANDALONE.bat`** OR double-click **`dist/index.html`** in File Explorer.
- The website is compiled into a standalone bundle and opens in any modern web browser.

---

### Option 2: Run Development Live Server
- Double-click **`START_WEBSITE.bat`**  
  **OR** run in terminal:
  ```bash
  npm run dev
  ```
- Open [http://localhost:3000](http://localhost:3000) in your browser.

---

### Option 3: Build for Hosting (Vercel, Netlify, Custom Domain)
- Run the build command:
  ```bash
  npm run build
  ```
- Upload the contents of the `dist/` folder to any web host or hosting provider.
